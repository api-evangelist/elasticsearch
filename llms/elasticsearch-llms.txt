# Elasticsearch

> Elasticsearch is an open source search and analytics engine for all types of data — textual, numerical, geospatial, structured, and unstructured. It exposes a RESTful API for indexing, searching, and managing data, with powerful aggregations and real-time analytics at scale. Maintained by Elastic.
